# 03_操作步骤

## 步骤 1：安装依赖

~~~bash
pip install -r requirements.txt
~~~

## 步骤 2：下载数据

~~~bash
python download_data.py
~~~

## 步骤 3：下载 BERT 权重（见 02_环境搭建.md §3）

## 步骤 4：冒烟测试（可选，快速验证）

~~~bash
python code/train_bert.py --device cuda --epochs 1 --limit 200 --batch 16
~~~

预期：TF-IDF ~0.76，BERT 微调 ~0.93，BERT 从头 ~0.10（1 epoch 2000 样本）

## 步骤 5：完整训练

~~~bash
python code/train_bert.py --device cuda --epochs 3 --batch 32
~~~

约 1.5 小时（RTX 5060 8GB），输出保存到 `output_text/result_summary.json`。

## 步骤 6：生成图表

~~~bash
python code/plot_bert.py
~~~

生成 `output_text/learning_curve.png` 与 `output_text/accuracy_bar.png`。

## 步骤 7：查看结果

~~~bash
cat output_text/result_summary.json
~~~

## 常见问题

- **HuggingFace 超时**：必须用 hf-mirror.com 镜像 + 本地路径加载（见 02 §3）。
- **Arrow 读取失败**：文件是 Arrow STREAM 格式，用 `pyarrow.ipc.open_stream`（不是 open_file）。
- **输出路径**：`train_bert.py` 默认写 `output_text/`（绝对路径，不会与 CIFAR 步骤冲突）。
