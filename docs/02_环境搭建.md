# 02_环境搭建

## 1. 硬件

- GPU：NVIDIA GeForce RTX 5060 Laptop，8GB 显存
- CPU：Intel/AMD x86_64

## 2. Python 环境

- Python 3.12.14，pip 26.2.1
- 使用国内镜像加速安装：

~~~bash
pip install torch torchvision --index-url https://mirrors.aliyun.com/pytorch-wheels/cu128/
pip install transformers tokenizers datasets scikit-learn tqdm pyarrow matplotlib numpy --index-url https://mirrors.aliyun.com/pypi/simple/
~~~

## 3. BERT-base-chinese 权重下载

**关键**：HuggingFace Hub 直连在本机超时，必须走 hf-mirror.com 镜像，且下载**原始文件**到本地路径再加载：

~~~bash
mkdir -p hf_cache/bert-base-chinese
# 从 https://hf-mirror.com/bert-base-chinese/resolve/main/ 下载：
curl -L -o hf_cache/bert-base-chinese/config.json https://hf-mirror.com/bert-base-chinese/resolve/main/config.json
curl -L -o hf_cache/bert-base-chinese/vocab.txt https://hf-mirror.com/bert-base-chinese/resolve/main/vocab.txt
curl -L -o hf_cache/bert-base-chinese/tokenizer_config.json https://hf-mirror.com/bert-base-chinese/resolve/main/tokenizer_config.json
curl -L -o hf_cache/bert-base-chinese/pytorch_model.bin https://hf-mirror.com/bert-base-chinese/resolve/main/pytorch_model.bin
~~~

然后 `train_bert.py` 从该**本地路径**加载：`BertTokenizer.from_pretrained(local)` / `BertForSequenceClassification.from_pretrained(local, num_labels=10)`。

## 4. THUCNews 数据下载

~~~bash
python download_data.py   # 下载 train/val/test 三个 arrow 文件到 data/
~~~

数据源：`https://hf-mirror.com/datasets/seamew/THUCNewsText/resolve/main/`（注意必须带 `/datasets/` 前缀，否则 404）。

## 5. 验证

python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
