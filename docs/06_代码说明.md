### 数据加载 load_arrow()

使用 pyarrow.ipc.open_stream（Arrow STREAM 格式，非 File 格式）。

~~~python
def load_arrow(path):
    import pyarrow.ipc as ipc
    with ipc.open_stream(path) as f:
        t = f.read_all()
    texts = [t.column(1)[i].as_py() for i in range(t.num_rows)]
    labels = [int(t.column(0)[i].as_py()) for i in range(t.num_rows)]
    return texts, labels
~~~

### train_bert()

支持两种初始化模式：

~~~python
if init_mode == scratch:
    config = BertForSequenceClassification.config_class.from_pretrained(BERT_LOCAL, num_labels=10)
    model = BertForSequenceClassification(config)          # 随机初始化
else:
    model = BertForSequenceClassification.from_pretrained(BERT_LOCAL, num_labels=10)  # 预训练
~~~

训练配置：

~~~python
opt = torch.optim.AdamW(model.parameters(), lr=lr, weight_decay=0.01)
sched = get_linear_schedule_with_warmup(opt, num_warmup_steps=int(0.1*total_steps), num_training_steps=total_steps)
torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)   # 梯度裁剪
~~~

每个 epoch 保存 {init_mode}_epoch{ep}.pt 权重到 OUT_DIR。

### 命令行参数

- --device：cuda / cpu
- --epochs：训练轮数（默认 3）
- --batch：batch size（默认 32）
- --max-len：序列最大长度（默认 128）
- --limit：每类样本上限（冒烟测试，默认 0=全量）
- --only：仅运行某个臂（ft / sc / tfidf / all）
